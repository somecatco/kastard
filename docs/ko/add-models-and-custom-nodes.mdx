---
title: "Worker 연결 후 모델 및 Custom Node 추가"
description: "연결된 Worker에 모델과 Custom Node를 추가합니다."
---

Worker에 연결한 후에도 모델을 동기화하거나 Custom Node를 설치할 수 있습니다.

## Custom Node 설치

1. ComfyUI Manager 또는 Custom Node 폴더에 직접 설치합니다.
2. `N`에서 `Sync Again`을 눌러 Worker와 동기화합니다.
3. `B`에서 `Restart`를 눌러 Worker의 ComfyUI를 다시 실행합니다.

## 모델 추가

1. Model Library에 모델을 추가합니다.
2. `M`에서 `Sync Again`을 눌러 Worker와 동기화합니다.
3. `B`에서 `Restart`를 눌러 Worker의 ComfyUI를 다시 실행합니다.
