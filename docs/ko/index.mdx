## 주요 기능

- ComfyUI 워크플로우 로컬 편집
- RunPod 및 Vast.ai GPU Worker에서 원격 실행
- RunPod 및 Vast.ai Worker 배포 링크 제공
- ComfyUI Backend, 모델 및 Custom Node 동기화
- Worker 연결·동기화·워크플로우 실행 상태 실시간 표시
- 로컬 입력 파일 자동 전송 및 실행 결과 표시
- SSH 터널을 통한 자동 암호화 연결
