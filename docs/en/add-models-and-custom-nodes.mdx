---
title: "Add Models and Custom Nodes After Connecting"
description: "Add models and Custom Nodes to a connected Worker."
---

After connecting to a Worker, you can still synchronize models or install Custom Nodes.

## Install a Custom Node

1. Install the Custom Node through ComfyUI Manager or directly in the Custom Node folder.
2. Select `Sync Again` in `N` to synchronize it with the Worker.
3. Select `Restart` in `B` to restart the Worker's ComfyUI.

## Add a model

1. Add the model to Model Library.
2. Select `Sync Again` in `M` to synchronize it with the Worker.
3. Select `Restart` in `B` to restart the Worker's ComfyUI.
