---
title: "Edit and Run Workflows"
description: "Edit workflows in Kastard and run them on a Worker."
---

## Check readiness

When a check appears on `B`, the Worker's ComfyUI is ready.

## Edit and run a workflow

Load or edit a workflow in ComfyUI, then run it. The connected Worker runs the workflow.

Local input files are transferred to the Worker automatically.

## View results

Results generated by the Worker appear in ComfyUI.
